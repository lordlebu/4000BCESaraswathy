# Prototype Source Plan

This folder is reserved for the first browser prototype of **South of Tethys: Jambhudweepa Adventure**.

Planned first files:
- `index.html`: canvas, controls, and journal layout.
- `styles.css`: cozy readable prototype styling.
- `main.js`: startup, input, rendering, and game loop.
- `generator.js`: deterministic world generation.
- `journal.js`: tile descriptions, discoveries, and creature notes.

The first implementation should avoid dependencies until the core exploration loop is proven.
