## Rebuild and layout

`python tools/import-fauna-jrpg.py <raw> <normalized-source>` imports four animal views;
add `--tram` for the sixteen-pose vehicle. Bounds use alpha only to find each sprite; source RGBA
samples remain unchanged by crop/nearest-neighbour resizing. One scale is shared across poses.

`python tools/build-twin-fauna.py` builds the sixteen 128×128 animal views, 768×640 tram-walk atlas
and 768×160 still atlas. It never writes Beedu unless explicitly invoked with `--beedu`.
The manifest `tools/twin-fauna.json` makes sources mandatory. Animal view order is right, left,
down, up. The generated tram rows are right, left, down, up; import explicitly swaps the last
two rows to the engine's **right, left, up, down** contract. Columns are idle, idle/breathe,
left stride, right stride. Do not reverse north/south vehicle art when rebuilding.
